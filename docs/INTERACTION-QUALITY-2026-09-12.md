# 交互效果改进与验收

日期：2026-09-12。响应“交互效果需要优于之前版本”的补充要求，保留浅色和原有布局，把改善落实到反馈可见性、操作距离、播放联动及回看能力。以下变化均已实现，并有可重复的操作验收。

| 交互问题 | 当前行为 | 验收证据 |
| --- | --- | --- |
| 修改配置后，需要滚动寻找结果 | 产能面板顶部固定显示吞吐、副本分配和峰值 KV；输入立即更新结果，无法部署显示原因 | 修改单位数量改变吞吐，滚动到表单底部后结果仍在视口内 |
| 预设与手动输入状态不清楚 | 当前预设有选中态；偏离预设后显示“自定义” | `aria-pressed` 与实际数值一致 |
| 窄屏操作负载时，抽屉遮住模型 | 切入负载演示后关闭流程抽屉，在模型下方就地显示控制与输出 | 390px / 900px 模型、播放按钮和 token 进度同时可见，无横向溢出 |
| 只能向前看演示，不易核对 KV 增长 | 可前后逐 token、拖动进度、跳转 prefill / decode；面板聚焦后支持空格、方向键、Home / End | 回看同一 token 的 KV 一致；不会接管输入框和原生滑块按键 |
| 负载计时推进，但已有粒子未跟随负载模式播放 | 3D 粒子、连线强调和硬件脉冲读取当前模式的播放状态；暂停同步停止 | WebGL 路径粒子可见且相位变化，暂停后相位稳定；原有粒子像素测试继续通过 |
| 短请求一闪而过，难以观察 | 1× 使用至少 8 秒的讲解节奏，界面注明其与模型计算时间的区别 | 改变节奏不改变计算总时长、token 总量或 KV 结果 |
| 负载提示遮住 2D 页签，缩小机架后标签难读 | 资源提示独立占位；总览适配高度，增加可点击的部件图例 | 页签可直接点击；图例能打开详情，Escape 后焦点返回原按钮 |

## 动效与状态边界

- 计算时钟仍由 DOM 驱动，3D 帧循环只绘制；无 WebGL 也能播放和逐 token 回看。
- 负载推进不自动移动相机；只有明确点击“定位瓶颈”等导航操作才改变视角。
- 减少动态效果关闭移动粒子与脉冲，保留进度和静态强调。切到后台会暂停，不在返回时跳过一段演示。
- 未改变硬件规格、产能公式和场景分享格式；计算限制继续常驻说明。
